1｜生活化导入

同学们，假设你是工厂的生产经理。今天老板拿着一张急单走过来：

“客户今天就要答复，这张订单我们能不能接？”

老板提出了三个生产要求：

每天产量超过500件
每天使用工人少于20人
每天生产成本低于3万元
🔍 问题1：这三个条件中，表示大小限制的关键词是什么？
这些条件给出的不是一个固定数值，而是数量之间的大小关系。
💡 问题2：如果每天产量为 \(x\) 件、使用工人数为 \(y\) 人、每天生产成本为 \(z\) 万元， 怎样用数学式准确表示老板的三个要求？
\[ x>500,\qquad y<20,\qquad z<3 \]
这些用不等号表示大小关系的式子，就是我们今天要研究的——不等式。

2｜不等式：是什么？怎么用？｜第102页

问题3：观察 \(11>10,\ -3<-2,\ x+3<2,\ x^2+5<6x\)，它们有什么共同特点？
用不等号“<”或“>”表示大小关系的式子，叫做不等式。
问题4：如果两个式子的大小不能直接看出来，怎样比较？
\(a-b>0\Rightarrow a>b\)
\(a-b=0\Rightarrow a=b\)
\(a-b<0\Rightarrow a<b\)
比较大小：作差 → 变形 → 判号 → 结论。

4｜例题1—3｜第102—103页

比较 \((x-5)(x+7)\) 与 \((x+5)(x-3)\) 的大小。

\[ \begin{aligned} &(x-5)(x+7)-(x+5)(x-3) &&\quad \text{【作差】}\\ ={}&(x^2+2x-35)-(x^2+2x-15) &&\quad \text{【展开】}\\ ={}&x^2+2x-35-x^2-2x+15 &&\quad \text{【去括号】}\\ ={}&-20 &&\quad \text{【化简】}\\ &<0 &&\quad \text{【判号】} \end{aligned} \]
\[ \therefore\ (x-5)(x+7)<(x+5)(x-3). \qquad \text{【得出结论】} \]
关键：作差不是目的，目的是把“比较两个式子的大小”转化为“判断差的正负”。
方法提炼：作差 → 展开 → 去括号 → 化简 → 判号 → 写结论。

比较 \((x^2-5)^2\) 与 \(x^4-10x^2+7\) 的大小。

\[ \begin{aligned} &(x^2-5)^2-(x^4-10x^2+7) &&\quad\text{【作差】}\\ ={}&(x^4-10x^2+25)-(x^4-10x^2+7) &&\quad\text{【展开】}\\ ={}&18 &&\quad\text{【化简】}\\ &\gt0 &&\quad\text{【判号】} \end{aligned}\]
\[\therefore\ (x^2-5)^2\gt x^4-10x^2+7.\qquad\text{【得出结论】}\]
关键：作差后继续化简，直到能够直接判断差的正负。

比较 \(x^2+15\) 与 \(10x-12\) 的大小。

\[ \begin{aligned} &x^2+15-(10x-12) &&\quad\text{【作差】}\\ ={}&x^2-10x+27 &&\quad\text{【去括号·合并】}\\ ={}&(x-5)^2+2 &&\quad\text{【配方】}\\ &\gt0 &&\quad\text{【判号】} \end{aligned}\]
\[\therefore\ x^2+15\gt10x-12.\qquad\text{【得出结论】}\]
关键：二次式不能直接判号时，可通过配方把正负结构显出来。

5｜随堂练习1｜第103页

比较下列各组式子的大小。先独立作答，再查看规范解答。

\((x+3)(x-1)\) 与 \((x+4)(x-2)\)

\[ \begin{aligned} &(x+3)(x-1)-(x+4)(x-2) &&\quad\text{【作差】}\\ ={}&(x^2+2x-3)-(x^2+2x-8) &&\quad\text{【展开】}\\ ={}&5 &&\quad\text{【化简】}\\ &\gt0 &&\quad\text{【判号】} \end{aligned}\]

所以 \((x+3)(x-1)\gt(x+4)(x-2)\)。

\((x+8)(x+10)\) 与 \((x+9)^2\)

\[ \begin{aligned} &(x+8)(x+10)-(x+9)^2 &&\quad\text{【作差】}\\ ={}&(x^2+18x+80)-(x^2+18x+81) &&\quad\text{【展开】}\\ ={}&-1 &&\quad\text{【化简】}\\ &\lt0 &&\quad\text{【判号】} \end{aligned}\]

所以 \((x+8)(x+10)\lt(x+9)^2\)。

\(x^2+6x\) 与 \(4x-2\)

\[ \begin{aligned} &x^2+6x-(4x-2) &&\quad\text{【作差】}\\ ={}&x^2+2x+2 &&\quad\text{【去括号·合并】}\\ ={}&(x+1)^2+1 &&\quad\text{【配方】}\\ &\gt0 &&\quad\text{【判号】} \end{aligned}\]

所以 \(x^2+6x\gt4x-2\)。

方法：若作差后得到二次式，可考虑配方后判号。

甲、乙两队正在参加一场积分闯关赛。上一轮结束后，甲队积分 \(a\) 高于乙队积分 \(b\)，即 \(a\gt b\)。

7｜不等式的性质：是什么？怎么用？｜第104页

问题7：除了“同乘”以外，不等式在传递、同加、同向相加时还遵循哪些规律？
性质1｜传递性
\(a>b,\ b>c\Rightarrow a>c\)
性质2｜同加
\(a>b\Rightarrow a+c>b+c\)
性质3｜同向相加
\(a>b,\ c>d\Rightarrow a+c>b+d\)
性质4｜同乘
\(a>b\)
\(c>0\)：\(ac>bc\)
\(c=0\)：\(ac=bc\)
\(c<0\)：\(ac<bc\)
使用性质：看清条件 → 选择性质 → 判断不等号方向。

例题4

已知 \(x\gt y\gt0\)，用不等号连接下列各式：

\(x-3\) 与 \(y-3\)

\[ \begin{aligned} &\because\quad x\gt y\\ &\therefore\quad x-3\gt y-3 \end{aligned} \]

\(y-5\) 与 \(x-2\)

\[ \begin{aligned} &\because\quad y\lt x,\quad -5\lt-2\\ &\therefore\quad y-5\lt x-2 \end{aligned} \]

\(-3x\) 与 \(-3y\)

\[ \begin{aligned} &\because\quad x\gt y,\quad -3\lt0\\ &\therefore\quad -3x\lt-3y \end{aligned} \]

\(3x\) 与 \(2y\)

\[ \begin{aligned} &\because\quad x\gt y,\quad 2\gt0\\ &\therefore\quad 2x\gt2y \qquad (1)\\ &\text{又，}\quad x\gt0 \qquad (2)\\ &\text{结合（1）及（2），得}\quad 2x+x\gt2y\\ &\text{即}\quad 3x\gt2y \end{aligned} \]

12｜要点小结

比较两个式子的大小

比较两个式子的大小，可以计算它们的差值。通过判断差的正、负或零，确定两个式子的大小关系。

\(A-B\gt0\Rightarrow A\gt B\)

\(A-B=0\Rightarrow A=B\)

\(A-B\lt0\Rightarrow A\lt B\)

四条基本性质

性质1　若 \(a\gt b,\ b\gt c\)，则 \(a\gt c\)。

性质2　若 \(a\gt b\)，则 \(a+c\gt b+c\)。

性质3　若 \(a\gt b,\ c\gt d\)，则 \(a+c\gt b+d\)。

性质4　若 \(a\gt b\)，则：

当 \(c\gt0\) 时，\(ac\gt bc\)；

当 \(c=0\) 时，\(ac=bc\)；

当 \(c\lt0\) 时，\(ac\lt bc\)。

关键提醒：不等式两边同乘一个数时，先判断乘数的正、零、负。

13｜练习15.1｜第105页

先独立完成，再按需展开规范解答。简单题保持简洁，典型题补充关键方法。

比较 \((x-4)^2\) 与 \((x-6)(x-2)\) 的大小。

\[ \begin{aligned} &(x-4)^2-(x-6)(x-2) &&\quad\text{【作差】}\\ ={}&(x^2-8x+16)-(x^2-8x+12) &&\quad\text{【展开】}\\ ={}&4\\ &\gt0 &&\quad\text{【判号】} \end{aligned}\]

所以 \((x-4)^2\gt(x-6)(x-2)\)。

比较 \(x^2+13\) 与 \(4x\) 的大小。

\[ \begin{aligned} &x^2+13-4x &&\quad\text{【作差】}\\ ={}&x^2-4x+13\\ ={}&(x-2)^2+9 &&\quad\text{【配方】}\\ &\gt0 &&\quad\text{【判号】} \end{aligned}\]

所以 \(x^2+13\gt4x\)。

比较 \((x-1)(x^2+x+1)\) 与 \((x+1)(x^2-x+1)\) 的大小。

\[ \begin{aligned} &(x-1)(x^2+x+1)-(x+1)(x^2-x+1) &&\quad\text{【作差】}\\ ={}&(x^3-1)-(x^3+1) &&\quad\text{【立方公式】}\\ ={}&-2\\ &\lt0 &&\quad\text{【判号】} \end{aligned}\]

所以前者小于后者。

关键：先识别立方差、立方和结构，可减少展开计算。

比较 \((x^2-x+1)(x^2+x+1)\) 与 \(x^4+x^2-1\) 的大小。

\[ \begin{aligned} &(x^2-x+1)(x^2+x+1)-(x^4+x^2-1) &&\quad\text{【作差】}\\ ={}&[(x^2+1)-x][(x^2+1)+x]-(x^4+x^2-1)\\ ={}&(x^2+1)^2-x^2-(x^4+x^2-1) &&\quad\text{【平方差】}\\ ={}&2\\ &\gt0 &&\quad\text{【判号】} \end{aligned}\]

所以前者大于后者。

比较 \((1-2x)(1+2x)\) 与 \((x^2-6)^2\) 的大小。

\[ \begin{aligned} &(1-2x)(1+2x)-(x^2-6)^2 &&\quad\text{【作差】}\\ ={}&1-4x^2-(x^4-12x^2+36)\\ ={}&-x^4+8x^2-35\\ ={}&-\big[(x^2-4)^2+19\big] &&\quad\text{【配方】}\\ &\lt0 &&\quad\text{【判号】} \end{aligned}\]

所以 \((1-2x)(1+2x)\lt(x^2-6)^2\)。

关键：把四次式看成关于 \(x^2\) 的二次式，再配方判号。

已知 \(y\lt x\lt0\)，用不等号连接下列各式：

（a）\(2x-3\) 与 \(2y-5\)

\[ \begin{aligned} &x\gt y &&\Rightarrow 2x\gt2y\\ &2x-3\gt2y-3\gt2y-5\\ &\therefore\ 2x-3\gt2y-5 \end{aligned} \]

（b）\(x^2\) 与 \(y^2\)

\[ \begin{aligned} &y\lt x\lt0 &&\Rightarrow -y\gt-x\gt0\\ &\therefore\ y^2\gt x^2\\ &\therefore\ x^2\lt y^2 \end{aligned} \]
易错点：两个数都为负数时，较大的数绝对值较小，因此平方后的大小关系反过来。
